Scripts PAC / WPAD (Auto-Configuração de Proxy)

Links dinâmicos de auto-configuração com Failover Transparente (Navega direto caso o servidor Squid fique offline)

Alta Disponibilidade (DIRECT)
Como funciona a resiliência dos scripts PAC gerados:
  • Squid ONLINE: As máquinas Windows navegam pelo proxy Squid na porta indicada, aplicando regras e gravando logs.
  • Squid OFFLINE: Se o servidor cair, o Windows faz failover automático para DIRECT (navega direto sem travar a internet).
  • Rede Local: Requisições para a intranet, IPs internos (10.x.x.x) e domínio *.pij.local navegam sempre direto.
